TraceText – Plagiarism Detection System

Project Overview

TraceText is a web-based plagiarism detection system developed as a Design and Analysis of Algorithms (DAA) mini project.

It compares two text documents and identifies common phrases using string matching algorithms.

Features

- Compare two text documents.
- Upload ".txt" files.
- Paste text directly.
- Calculate text similarity percentage.
- Display matching phrases.
- Select different string matching algorithms.
- Adjustable phrase length.
- Simple and responsive user interface.

Algorithms Used

1. Naive String Matching
2. Rabin-Karp Algorithm
3. Knuth-Morris-Pratt (KMP) Algorithm

Technologies Used

- HTML
- CSS
- JavaScript

How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html".
4. Right-click and select Open with Live Server.
5. The website will open in your browser.

How to Use

1. Enter text in Document A.
2. Enter text in Document B.
3. Select a matching algorithm.
4. Choose the phrase length.
5. Click Compare Documents.
6. View the similarity percentage and matching phrases.

Note

This project is developed for educational purposes. It identifies exact matching phrases and does not provide a definitive plagiarism verdict.
